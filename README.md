## 👋 Hello — I'm Sourojit

**Senior Application Developer at Webskitters Technology Solutions Pvt. Ltd., Kolkata, India — since July 2021.**

I build production web interfaces with **React, Next.js, and TypeScript** — the kind of interfaces people use every day: admin dashboards, enterprise data tables, onboarding and document flows, plan and payout management, and multi-tenant SaaS products.

My focus is practical, not decorative: clean architecture, reusable components, strong TypeScript, good performance, and polished, professional UI/UX that holds up in production.

> Building and shipping independent web products since January 2020. On GitHub since 19 April 2020.
